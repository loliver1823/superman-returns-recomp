# Security

> Drafted with AI assistance (Claude) for the project owner.

## Reporting a problem

Report security problems privately, not as a public issue: use the "Report a vulnerability" button on
this repository's Security tab when it is there. If it is not, open an issue that says only that you have
a security report, with no details. Include the commit you built, what an attacker could do, and the
steps to reproduce it.

Development is paused, so there is no promised response time, and a report may not be answered.

## What counts

- Code execution or file access through a mod, a save file or a settings file.
- A build or package that carries anything other than what this repository and your own disc produce.
- Anything in the repository that should not be public (credentials, personal data).

## Downloads

This project publishes no builds: it is source only. A prebuilt copy offered anywhere is not from this
project.
