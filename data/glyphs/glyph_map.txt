# Button-prompt glyph map (iter-464 input lane; docs/INPUT_GLYPHS.md).
# Read by gfx/glyph_subst.cpp from <exe dir>/data/glyphs/ (CMake copies this folder next to
# the exe). A texture pack may restyle prompts by editing this file and its PNGs.
#
#   canvas <n>                      replacement texture size (square, full mip chain)
#   tex <id> <fmt> <w> <h> <len> <fnv1a64>
#       a game icon texture: Xenos format, size, and FNV-1a-64 of its first <len> guest bytes
#       (generated and checked against ui.AST by tools/glyphs/glyph_map.py --print / --check)
#   use <set> <tex id> <recipe> [extent] [dx dy]
#       set:    ps4 | ps5 | switch | keyboard   (xbox = the game's own 360 icons, always)
#       recipe: keep | blank | png:<path> | key:<Control> | cluster:<Up>,<Left>,<Down>,<Right>
#               key: = the key or mouse input bound to that 360 control in the current
#               context (kernel/host_input.hpp promptInputFor: the controls lane's input.ini)
#       extent: the visible glyph's size as a fraction of the texture (match the original's
#               opaque extent); dx dy shift it by texture fractions
#   keyglyph <input name, spaces as _> <path>   keyboard/mouse art per input: SDL key names,
#               Mouse1..Mouse5 (left, right, middle, X1, X2), WheelUp, WheelDown, Wheel,
#               MouseMove (the mouse drives the control: mouse-look on the right stick)
#   keydefault <path>                           an input with no art of its own, or unbound
#
# Art: Julio Cacko, "FREE Input Prompts Pack" (CC0 1.0) - juliocacko_input_prompts/SOURCE.md.
