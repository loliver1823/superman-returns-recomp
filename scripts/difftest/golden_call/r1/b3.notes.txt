R1 batch 3 - L6 golden_call cases (archive/r1/l6/b3.script, 63 cases)
Generated from fake objects; scratch window 0x70000000..0x70DFFFFF unless noted. Each case's
fixture is written in full, so cases do not depend on each other. (Until phase 4 row 8 there was
one exception: sub_82764348's cut counter was per thread and cumulative across calls, so the two
gctm cases had to keep their order; the cut and its fire case are gone, see below.)
The riskier cases (writes outside the scratch window, the real allocator, the CRT TLS path, a
1 s wall-clock wait) are LAST, so a harness crash there cannot hide the earlier cases.

Writes outside the scratch window (all restored by END):
  0x822979C0      code bytes; zeroed only to make the dead store-if-zero of sub_82764760 /
                  sub_82767DF0 fire (golden holds 4E800421 there, so it never fires otherwise).
  0x82100000..    .text bytes used as a fake object at an address >= 0x82000000: the lua_State
                  for pushstr/pushvfstring (their guard refuses every L below 0x82000000, which
                  includes the whole scratch window) and the instruction node of the
                  ExpandNativeAluOps normal case (same guard on node links).
  0x829A93F0/24   DOGMA heap-range table count/pointer, redirected to a fake one-entry table so
                  the heap lookup owns a scratch pointer (DogmaFree normal cases).
  0x00000000..07  lgcmark fire case: after the splice zeroes the thread bounds, traversestack
                  reads [4] and stores 0 to [0]; zeroed first so that walk is one word.
  0x5E7A440C..13  typeerror key case: the operand itself is the key, and its tt is read at entry.
Harmless vtable target used everywhere a dispatch is needed: sub_828CCE50 (returns [r3+8] & 1,
reads only).

Environment knobs: none. No splice in this batch reads getenv (checked over all 23 bodies in
tools/regen/splice_bodies.json), so there is no "knob-off path = generated code (was a hand
copy)" case here. All 23 splices were ungated, and so are their hooks.
