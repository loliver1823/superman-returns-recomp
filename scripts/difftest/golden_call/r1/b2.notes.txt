R1 batch 2 - L6 golden_call cases (archive/r1/l6/b2.script): what each case exercises
=====================================================================================
59 cases, all 24 functions. Every case runs on the old splice body and on the hooked pristine
body (kernel/r1_hooks_b2.cpp + tools/regen/r1_hooks_b2.toml); printed registers and changed-page
hashes must match. All numbers are hex. The script is generated by a small Python script (kept
out of the repo); the fixtures below are what it writes.

Shared fixtures (written by W inside each case that needs them; memory is restored at END)
- NULLSUB 0x8214ABA8 = sub_8214ABA8, a bare blr (returns r3 unchanged); mapped, no override.
- GETTER 0x826E5838 = sub_826E5838: r3 = *(0x829A2434) whatever r3 was. Cases set 0x829A2434 to
  a fake object (resource manager) or to an empty array E = [0] at 0x70000600, so a graph node
  whose vtable+8 is GETTER has no dependencies.
- "self node" N (sub_8271E5B0 / E630): *(N) = N, N+4 = 0, N+8 = NULLSUB. vt[2](N) returns N, and
  N read as an array is [N, 0], so the walk recurses into the same node forever.
- Graph nodes carry +64 (refcount; sub_8271F260 adds, sub_8271F368 subtracts) and +68 (inited
  byte = 1, so sub_8271F2C8 returns 1 without running the module's init vt[7]). Their CS (+4)
  goes through the harness's Rtl*CriticalSection stubs.
- 0x829A2BB0 (runner list) and 0x829A2BBC (runner listeners) are set to 0 where a case reaches
  sub_8271F108 or the listener broadcasts, so no golden runner / listener code runs.

Harness assumptions to check when running
- Unmapped golden memory (scratch 0x70000000.., page 0) reads as zero and is writable.
- Order matters for host thread_local state that the splice also kept per thread:
  * sub_8271E6B8 / sub_8271EA20 share a 200 ms timer: the E6B8 case runs before the EA20 cases
    (EA20 arms the timer; an E6B8 call more than 200 ms later would abort at entry).
  * sub_82763EE8's 50000 list counter is cumulative per thread and only the outer-cap case
    advances it (to 50001, which fires and resets it to 0).
- Large zero reads not written by W: 82763EE8_array_500000_cap_fire (0x70100000..0x704D0910)
  and 82763EE8_node_500000_cap_fire (0x70100000..0x70B00000).
- Other batches' conversions on the paths: sub_825FC108 (CS enter, core hook 0x825FC178 not
  reached with deadline -1), sub_824680C0 (clock, only in 82600E38_deadline_passed), the
  sub_8271F2C8 / sub_824692A8 / sub_825FC108 / sub_82720650 / sub_827623B8 / sub_826D4930 /
  sub_826E55F8 / sub_8271ED68 / sub_825FD958 kernel overrides (observe or conditional), the CRT
  exit chain (EXIT cases). sub_825FD958's override (dogma_hash_hooks.cpp) delegates
  CONDITIONALLY; if it does not call __imp__ for these inputs the two FD958 cases do not reach
  the hooks.

Knob-off path = generated code (was a hand copy) - coordinator rule
- sub_82762B10 SR_VM_FRAME_CLAMP (default ON): =0 -> the hook does nothing, generated code runs
  (the splice skipped its clamp block; no hand copy existed).
- sub_8271E630 SR_NATURAL_MODULE_INIT (read through sr::kernel::naturalModuleInitOn(), default
  ON = natural): the =0 legacy 2 s init timeout (entry skip + sub_8271F2C8 skip) is not ported;
  knob-off path = generated code (was a hand copy of the timeout/skip path).
- sub_8271E630 SR_E630_TRACE (opt-in, logs only): no hook.
